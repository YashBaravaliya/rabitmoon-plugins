# rabitmoon infography plugins

Category: **Productivity**. Official packages maintained by rabitmoon for creating editable infographics, presentations, diagrams, charts and reports.

These packages are **beta submission drafts**. They are not yet approved or publicly listed by OpenAI or Anthropic. Service access currently requires an approved rabitmoon beta account. Installing a package does not grant access.

- `openai/`: portable Agent Plugins package for OpenAI directory upload.
- `claude/`: Claude plugin bundle with skills and remote MCP configuration.
- MCP endpoint: https://api.rabitmoon.com/mcp

The hosted backend and application source are not part of this repository. Each bundle includes the original logo, four focused skills, maintained visual/design references and a sample five-page request. Each has its own plugin-only LICENSE.

Creation and editing use account credits. Failed or cancelled jobs can incur charges for consumed work. Returned document URLs require the owner to sign in.

Claude submission remains pending dedicated OAuth testing and resolution of its directory restriction on AI image generation. The current MCP supports optional image briefs; do not treat this package as approval or complete Claude compatibility.
